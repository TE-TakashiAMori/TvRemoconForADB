# Screen Record Use Case - 画面録画機能

## 概要
Android TVの画面を動画として録画する機能を提供します。ADBの`screenrecord`コマンドを使用して、デバイスの画面をMP4形式で保存します。

## ユースケース

### UC-SR-001: 時間指定での画面録画
**アクター**: ユーザー  
**前提条件**: 
- Android TVデバイスがADB経由で接続されている
- デバイスがAndroid 4.4 (KitKat) 以上である

**メインフロー**:
1. ユーザーが録画時間を指定して録画を開始する
2. システムがデバイス上で`screenrecord`コマンドを実行する
3. 指定時間経過後、自動的に録画が停止する
4. システムが録画ファイルをローカルにダウンロードする
5. 保存先とファイルサイズをユーザーに通知する

**代替フロー**:
- 3a. ユーザーが指定時間前に手動停止した場合、その時点で録画を終了する
- 4a. ファイルのダウンロードに失敗した場合、エラーメッセージを表示する

### UC-SR-002: 手動での画面録画（開始/停止）
**アクター**: ユーザー  
**前提条件**: 
- Android TVデバイスがADB経由で接続されている

**メインフロー**:
1. ユーザーが録画開始ボタンを押す
2. システムがバックグラウンドで`screenrecord`を開始する
3. 録画中であることをユーザーに表示する（タイマー表示）
4. ユーザーが録画停止ボタンを押す
5. システムが録画を停止し、ファイルをダウンロードする
6. 保存先をユーザーに通知する

**代替フロー**:
- 3a. 最大録画時間（3分）に達した場合、自動的に停止する
- 4a. デバイスとの接続が切れた場合、エラーメッセージを表示する

## 機能要件

### FR-SR-001: 録画形式
- **形式**: MP4
- **コーデック**: H.264（デバイスデフォルト）
- **解像度**: デバイスのネイティブ解像度（元サイズ）
- **フレームレート**: デフォルト設定を使用

### FR-SR-002: 録画時間制限
- **最大録画時間**: 180秒（3分）
  - Androidの`screenrecord`コマンドの仕様による制限
- **最小録画時間**: 1秒
- **デフォルト録画時間**: 30秒（時間指定モード）

### FR-SR-003: ファイル管理
- **保存先**: スクリーンショットと同じディレクトリ（`~/remocon_screenshots`）
- **ファイル名**: 自動生成
  - フォーマット: `screenrecord_YYYYMMDD_HHMMSS.mp4`
  - 例: `screenrecord_20251022_153045.mp4`
- **カスタムディレクトリ**: ユーザーが保存先を指定可能

### FR-SR-004: 状態管理
録画中の状態を適切に管理し、以下の状態を持つ:
- **IDLE**: 待機中
- **RECORDING**: 録画中
- **STOPPING**: 停止処理中
- **COMPLETED**: 録画完了
- **ERROR**: エラー発生

## 非機能要件

### NFR-SR-001: パフォーマンス
- 録画開始までの遅延: 3秒以内
- ファイルダウンロード: 1MB/秒以上の転送速度

### NFR-SR-002: エラーハンドリング
- デバイス接続エラーの適切な通知
- ストレージ容量不足の事前チェック
- 録画中のエラー回復処理

### NFR-SR-003: ユーザビリティ
- 録画中の経過時間表示
- 残り時間の表示（時間指定モード）
- 録画状態の視覚的フィードバック

## CLI インターフェース仕様

### 基本コマンド
```bash
# 30秒録画（デフォルト）
remocon-adb record

# 時間指定録画
remocon-adb record --duration 60    # 60秒録画
remocon-adb record -d 120           # 120秒録画

# ファイル名指定
remocon-adb record -f my_recording.mp4

# 保存先指定
remocon-adb record --directory ~/Videos

# 組み合わせ
remocon-adb record -d 90 -f demo.mp4 --directory ~/Desktop
```

### 手動停止モード
```bash
# 時間制限なし（Ctrl+Cで停止）
remocon-adb record --manual

# 手動停止（明示的なオプション）
remocon-adb record --duration 0
```

### オプション一覧
| オプション | 短縮形 | 説明 | デフォルト |
|-----------|--------|------|-----------|
| `--duration` | `-d` | 録画時間（秒）、0で手動停止モード | 30 |
| `--filename` | `-f` | 出力ファイル名 | 自動生成 |
| `--directory` | `-dir` | 保存ディレクトリ | `~/remocon_screenshots` |
| `--manual` | `-m` | 手動停止モード（Ctrl+Cで停止） | False |
| `--device` | `-d` | 対象デバイスID | 最初のデバイス |

### 動作仕様

#### 録画開始ボタン
- 状態: 待機中のみ有効
- 押下時:
  - 録画を開始
  - ボタンを無効化
  - 停止ボタンを有効化
  - タイマーを開始
  - 状態表示を「録画中」に変更

#### 停止ボタン
- 状態: 録画中のみ有効
- 押下時:
  - 録画を停止
  - ファイルをダウンロード
  - 状態を「停止処理中」に変更
  - 完了後、「完了」に変更

#### タイマー表示
- **録画中**: `経過時間: 01:23 / 03:00`
- **手動停止モード**: `経過時間: 01:23 (手動停止)`
- **待機中**: `経過時間: --:--`

#### 手動停止チェックボックス
- チェック時: 録画時間入力を無効化
- チェック解除時: 録画時間入力を有効化

## ADBコマンド仕様

### 基本コマンド
```bash
# デバイス上で録画開始（3分制限）
adb shell screenrecord /sdcard/recording.mp4

# 時間指定録画（60秒）
adb shell screenrecord --time-limit 60 /sdcard/recording.mp4

# ファイルダウンロード
adb pull /sdcard/recording.mp4 ~/local/path/recording.mp4

# デバイス上のファイル削除
adb shell rm /sdcard/recording.mp4
```

### プロセス管理
```bash
# バックグラウンドで実行
adb shell "screenrecord /sdcard/recording.mp4 &"

# プロセスID確認
adb shell "ps | grep screenrecord"

# プロセス停止
adb shell "kill -INT <PID>"
```

## エラーケース

### E-SR-001: デバイス非対応
- **エラー**: デバイスがAndroid 4.4未満
- **対処**: エラーメッセージを表示し、録画を開始しない

### E-SR-002: ストレージ容量不足
- **エラー**: デバイスのストレージが不足
- **対処**: 事前チェックでエラーを通知

### E-SR-003: 録画中の接続断
- **エラー**: 録画中にデバイス接続が切れた
- **対処**: エラーログを記録し、ユーザーに通知

### E-SR-004: ファイル転送失敗
- **エラー**: 録画ファイルのダウンロードに失敗
- **対処**: リトライロジックを実行、失敗時はエラー通知
